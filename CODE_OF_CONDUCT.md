# Code of Conduct

Este projeto adota o Contributor Covenant Code of Conduct.

## Our Pledge

Participantes devem colaborar com respeito, empatia e profissionalismo.

## Unacceptable Behavior

Nao serao tolerados assedio, ataques pessoais, discriminacao, divulgacao de informacoes privadas ou qualquer conduta que torne o ambiente inseguro.

## Enforcement

O mantenedor pode remover comentarios, rejeitar contribuicoes ou bloquear participantes que violem este codigo.
